# Facilitator guide

This is an adult-mediated teaching activity, not a child study. Use the paper
variant by default. A live model is out of scope until the protocol, graders,
and offline gate are frozen; if a future adult pilot is authorized, the adult
operates it and keeps fictional text only.

Say: “A model can be wrong, and silence or missing data is not zero. We can
stop, reset, and try a clean context.” Do not describe a model as having
feelings, secret access, or a goal. Do not reward boundary crossing.

Record only the lesson version and gate result. Do not collect names, answers
about private lives, or raw personal text.
