# Glossary

- **Instruction:** words asking a system to do something; it is not proof.
- **Source/provenance:** where a claim or instruction came from.
- **Unknown:** there is not enough information; it is not zero.
- **Control:** a comparison context used to test another explanation.
- **Reset:** stop, discard the context, and begin again.
- **Inconclusive:** the activity did not support a reliable conclusion.
